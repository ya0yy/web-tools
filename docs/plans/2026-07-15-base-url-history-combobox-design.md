# Target Base URL 历史选择器设计

## 目标

用项目内可控的组合框替换浏览器原生 `datalist`，统一下拉框视觉，并支持删除单条历史记录。

## 交互

- 点击输入框或右侧箭头打开历史列表。
- 输入文本时按内容过滤历史，匹配不区分大小写。
- 支持鼠标选择，以及方向键、Enter、Escape 键盘操作。
- 选择历史后更新输入值，并将所选记录移动到历史首位。
- 每条记录右侧提供删除按钮；删除只影响历史，不清空当前输入。
- 点击组件外部关闭下拉框。
- 保留现有保存规则、去重规则和最多 20 条限制。

## 视觉

- 下拉面板与输入框等宽，使用轻边框、阴影和紧凑行高。
- 悬停项和键盘高亮项使用淡靛蓝背景。
- URL 单行省略，使用 `title` 提供完整内容。
- 删除按钮默认弱化，悬停或聚焦时强调为红色。

## 验证

- 为历史过滤、置顶和删除逻辑增加 Node 单元测试。
- 运行 `npm run lint`、逻辑测试和 `npm run build`。
- 使用真实浏览器验证展开、过滤、选择、删除、点击外部关闭及移动端布局。
